## 📌 Overview
CRYPT is a lightweight command-line Python application that is used for basic credential storage and simple access control that can be used on Windows, Linux, and MacOS.

## ⚙️ Features
- Master password protection for access control
- Store account credentials
- Retrieve saved data
- Simple and easy-to-use command-line interface

## 💻 How to use
### Main Menu Options:
```
 1. Password Management
 2. Reset CRYPT Password 
 3. Exit
Option: 
``` 
- Password Management: allows the user to access all of CRYPT's password managing features.
- Reset CRYPT Password: allows the user to reset their password used to access CRYPT.
- Exit: terminates the program.
  
### Password Management Options: 
```
Choose option:
 1. Save new password
 2. Search for password
 3. Update password
 4. Delete password
 5. View all saved passwords
Option: 
```
- Save new password: allows the user to store new credentials.
- Search for password: searches for the account and password the user is looking for.
- Update password: allows the user to update one of their previously stored credentials.
- Delete password:  deletes previously stored credentials selected by the user. 
- View all: allows the user to see a list of all saved credentials.



## ⚠️ Security Warning
  Because this program does not yet use encryption to protect stored data, it is recommended to keep the application on a flash drive or other local storage device to reduce exposure and keep your information out of reach.
